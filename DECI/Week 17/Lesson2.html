Dialogs: alert, confirm, prompt

1. alert()

The alert() function shows a message box. It pauses code execution until the user clicks "OK".

2. confirm()

The confirm() function asks a yes/no question. It pauses code until the user responds. It returns true if "OK" clicked, false if "Cancel".

3. prompt()

The prompt() function asks the user to input some text. It pauses until the user responds. It returns the input string or null if canceled.

Results

Discussion:

  • Pause behavior: All three dialogs pause code execution until the user responds.
  • Limitations: They are blocking, modal, and can be disruptive to user experience.
  • When to use: Best for simple, critical alerts or confirmations. Avoid overusing them in modern UIs; consider custom modal dialogs instead.
