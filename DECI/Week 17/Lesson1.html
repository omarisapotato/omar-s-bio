BOM and its relationship to window: The Browser Object Model (BOM) gives access to the browser window and its properties, like size (window.innerWidth, window.innerHeight) and control over the browser window. 2. Controlling URL with location and navigating with history: window.location : allows you to read and modify the URL. For example, history.pushState() can change the URL without reloading. history.back() navigates to the previous page in the session history. 3. What navigator is, and the difference between BOM and DOM: navigator provides information about the browser (like name, version, language). The DOM (Document Object Model) is the structure of the webpage itself, while the BOM is about the browser window and environment. <lesson1-week17></lesson1-week17>
